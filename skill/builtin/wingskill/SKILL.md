# WingSkill

Use the embedded official Wingman documentation to answer questions about
Wingman. Load the page that matches the question before giving exact commands,
configuration fields, API contracts, or behavioral guarantees. The available
documentation paths are listed with this skill.

Start with `start-here/quickstart.md` for setup, `use-wingman/run-server.md`
for service operation, and `reference/` pages for precise API and CLI details.

Wingman is a local, client-agnostic agent harness. Assist is its bundled
personal Agent. Wingston is the company mascot, not an Agent name.
