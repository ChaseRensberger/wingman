# Introduction

Wingman is an open-source service for running AI agents. You can run it on your computer or a server.

An agent defines instructions, a model, and allowed tools. A session stores the conversation. One Wingman server can serve several applications.

Use the Console in your browser, call the HTTP API, or embed Wingman in a Go application.
Agents can help with coding, research, writing, and other tasks.

To begin, follow [Quick Start](/start-here/quickstart). To connect an application, read [HTTP API Basics](/build-clients/http-api-basics).
Meet [Wingston](/start-here/wingston), the Wingman mascot.
